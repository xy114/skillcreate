# 分类引擎漏洞修复设计方案

## 概述

对 `skill/分类引擎.py` 和 `skill/分类标准.md` 进行针对性修复，解决代码审查中发现的 15 个漏洞。修复不改变 LLM 驱动的核心架构，仅在现有框架内加固。

## 修复清单

### 一、输入输出加固（4 项）

**C4: CSV UTF-8 BOM 崩溃**
- 位置: `分类引擎.py` 第 170 行
- 问题: Excel 导出的 CSV 含 BOM，`csv.DictReader` 将 `﻿` 纳入首列名，`row["关键词"]` 抛出 KeyError
- 修复: `encoding="utf-8"` → `encoding="utf-8-sig"`

**C8: 去重保留策略错误**
- 位置: `分类引擎.py` 第 178-187 行
- 问题: 去重时保留首次出现行的搜索量，而非最大值
- 修复: 比较搜索量数值，保留最大值行

**C9: 清理 import**
- 位置: `分类引擎.py` 第 16 行、第 79 行
- 问题: `import re` 当前未使用，但 C2 修复需要用到；`import urllib.request` 在函数内
- 修复: 保留 `import re`（供 C2 括号剥离使用），将 `urllib.request` + `urllib.error`（供 N4 重试使用）移到文件顶部

**N2: 判断理由列被丢弃**
- 位置: `分类引擎.py` 解析函数和输出列
- 问题: Prompt 要求 AI 输出 6 列（含判断理由），解析器只取前 5 列，理由信息丢失
- 修复: 解析 `parts[5]`，CSV 输出列新增「判断理由」

### 二、LLM 调用健壮性（4 项）

**C3: f-string 解析 Markdown 风险**
- 位置: `分类引擎.py` 第 81 行
- 问题: `分类标准` 内容嵌入 f-string，若含 `{` 或 `}` 字符运行时报错
- 修复: f-string → **纯字符串拼接**（注意：`.format()` 同样解析 `{}`，不适用）
- 实现:
```python
系统提示 = 分类标准 + "\n\n---\n**当前任务的产品类目**: " + 类目 + "\n\n请严格按分类标准完成上述关键词分类任务。直接输出分类结果，不要输出额外的解释或开场白。"
```

**C1: API 响应解析脆弱**
- 位置: `分类引擎.py` 第 109 行
- 问题: `body["content"][0]["text"]` 无类型/长度检查，空 content 或 tool_use block 导致崩溃
- 修复: 检查 `len(content) > 0`，过滤 `type == "text"` 的 block，合并多个 text block

**C6: 失败原因混淆**
- 位置: `分类引擎.py` 调用_LLM_分类 和 处理关键词表
- 问题: 无 API Key 和 API 调用失败都返回 `""`，提示信息误导用户
- 修复: 无 Key → `None`，API 失败 → `""`，调用方区分处理
- 具体提示信息：
  - `llm结果 is None` → `"⚠️  未配置 ANTHROPIC_API_KEY，输出 Prompt 预览。设置环境变量后重新运行即可调用 AI 分类。"`
  - `llm结果 == ""` → `"❌ AI 分类失败（已重试 2 次），请检查网络或密钥有效性后重试。"`

**N4: API 无重试机制**
- 位置: `分类引擎.py` 第 97-111 行
- 问题: 瞬态网络故障导致整个批次退回 Preview 模式
- 修复: 2 次重试 + 指数退避（1s / 2s），仅对 URLError/HTTPError/OSError 重试

### 三、解析器修复（5 项）

**N1: 输出格式不一致**
- 位置: `分类标准.md` + Prompt
- 问题: 分类标准.md 定义 5 列，Prompt 要求 6 列，不一致可能导致解析失败
- 修复: 统一为 6 列（序号 | 关键词 | 分类 | 属性标签 | 建议动作 | 判断理由）

**C2: 分类名子串匹配误判**
- 位置: `分类引擎.py` 第 147-150 行
- 问题: `"一级核心词" in "准一级核心词"` = True，错误归类
- 修复: `in` → 精确匹配。匹配前先用正则去除 AI 可能附加的括号注释（如 `"一级核心词（品类认知类）"` → `"一级核心词"`），再与 `有效分类` 集合做精确匹配
- 实现:
```python
import re   # C9 修复后重新导入（有用）
分类_标准化 = re.sub(r'[（(][^)）]*[)）]', '', 分类).strip()
分类 = 分类_标准化 if 分类_标准化 in 有效分类 else ""
```

**C5: 死代码**
- 位置: `分类引擎.py` 第 138-143 行
- 问题: `str.isdigit()` 从不抛 ValueError，`except ValueError` 分支不可达
- 修复: 删除 try/except，保留 `if not 序号.isdigit(): continue`

**C10: 建议动作无校验**
- 位置: `分类引擎.py` 第 152-157 行
- 问题: 分类有 `有效分类` 集合校验，建议动作无对应校验
- 修复: 新增 `有效建议动作` 集合 = `{"建议投放", "仅Listing嵌入", "建议否定", "待判定"}`，输出前校验

**N5: 分类映射静默覆盖**
- 位置: `分类引擎.py` 第 222 行
- 问题: dict 推导式 `{r["关键词"].lower(): r for r in 分类数据}` 静默覆盖重复行
- 修复: 检测重复关键词，打印告警，保留首次出现

### 四、边界条件（2 项）

**N3: 有效词可能为负数**
- 位置: `分类引擎.py` 第 261 行
- 问题: `有效词 = 去重后 - 不相关/宽泛词`，异常时可能为负
- 修复: `max(0, 去重后 - 不相关/宽泛词)`

**C7: LLM 遗漏关键词静默误分类**
- 位置: `分类引擎.py` 第 222-225 行
- 问题: 分类映射 `.get(kw, default)` 默认值 `"不相关/宽泛词"`，无法区分 AI 判定和 AI 遗漏
- 修复: 遗漏时分类标为 `"未分类"`，收集遗漏列表并打印告警，最多显示前 10 个

### 五、分类标准文档修正（2 项）

**N1: 输出格式统一为 6 列**（见上文）

**N6: 三级场景词优先级修正**
- 位置: `分类标准.md` 分类优先级节
- 问题: 三级场景词要求「信号词 + 属性词」，纯信号词无分类路径跌入兜底
- 修复: 改为「包含场景/痛点/时效信号词，无论是否含属性词」
