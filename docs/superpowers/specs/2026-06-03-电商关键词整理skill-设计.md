# 跨境电商关键词整理 Skill 设计方案

## 概述

为悟空智能体平台设计一个 **关键词自动整理 Skill**，服务于跨境电商（亚马逊）产品开发立项流程。该 Skill 接收运营人员上传的关键词原始数据（Excel），自动完成关键词的**去重清洗 → 词频统计 → 三级分类 → 标签标注 → 结构化输出**，将原本人工耗时数小时的重复性工作压缩到分钟级。

MVP 先聚焦关键词整理环节，跑通验证后扩展至 Listing 文案自动生成 + 广告规划。

## 目标平台

**阿里悟空智能体平台**（钉钉生态内低代码/零代码工作流引擎）

关键约束：
- 运行在容器级安全沙箱中，权限继承钉钉组织权限
- 可调用 HTTP API（需经过企业网络代理）、钉钉原生能力（文档、通讯录）
- **不能**直接操控浏览器、不能访问本地文件系统

## 架构设计

### 整体数据流

```
钉钉群聊 @悟空 + 上传Excel
        │
        ▼
┌─────────────────────────────────┐
│  悟空 Skill（沙箱内运行）         │
│                                 │
│  ① 输入解析节点                  │
│     解析 Excel / 读取钉钉文档表格  │
│                                 │
│  ② 预处理节点                    │
│     去重、清洗、词频统计           │
│                                 │
│  ③ 分类引擎节点（核心）            │
│     规则匹配 → 三级分类 + 标签     │
│                                 │
│  ④ 输出组装节点                  │
│     组装结构化表格 + 生成群摘要    │
│                                 │
└─────────────────────────────────┘
        │
        ▼
  输出1: 结构化表格 → 钉钉文档
  输出2: 摘要卡片  → 钉钉群消息
```

### 分类引擎规则（核心）

采用三级分类体系，按以下流水线逐词处理：

```
原始关键词
    │
    ├─ ① 品牌/竞品词库匹配 → 命中 → 标为「品牌词」或「竞品词」
    │       ↓ 未命中
    ├─ ② 属性词库匹配
    │     ├─ 命中 ≥2 个属性维度 → 标为「二级属性词」
    │     ├─ 命中 1 属性 + 场景/痛点信号词 → 标为「三级场景词」
    │     └─ 命中 1 属性维度 → 标为「二级属性词」
    │       ↓ 未命中任何属性
    ├─ ③ 纯品类词判定 → 命中品类词库 → 标为「一级核心词」
    │       ↓ 未命中
    └─ ④ 相关性兜底 → 与类目相似度 < 阈值 → 标为「不相关/宽泛词」
```

#### 需维护的词库

| 词库 | 内容 | 示例 | 维护频率 |
|------|------|------|----------|
| 品牌/竞品词库 | 类目内已知品牌 + 竞品品牌 | 戴森、飞利浦、小米 | 手动追加，低频 |
| 属性词库（四维度） | 功能词、规格词、人群词、场景词 | 降噪、256GB、儿童、户外 | 类目切换时配置 |
| 品类词库 | 该类目下的基础品类名称 | 蓝牙耳机、连衣裙、沙发 | 类目切换时配置 |
| 场景/痛点信号词 | 触发三级分类的关键词 | 急救、防脱、小户型、差旅 | 类目切换时配置 |

#### 三级分类定义

| 分级 | 定义 | 特征 | 策略 |
|------|------|------|------|
| 一级核心词 | 基础品类词，无属性修饰 | 搜索量大，意图模糊 | 品牌曝光，非主力投放 |
| 二级属性词 | 核心词 + 属性（功能/规格/人群/场景） | 意图明确，转化率中高 | **主力投放**，详情页核心 |
| 三级场景词 | 问题/场景/痛点驱动 | 搜索量最小，转化率最高 | 高转化落地页，内容营销 |
| 品牌词 | 具体品牌名 | 转化率最高 | 100% 覆盖防御 |
| 竞品词 | 竞品品牌名 | 意图在比较 | 差异化优势时使用 |
| 不相关/宽泛词 | 与类目相似度低于阈值 | 无转化价值 | 建议否定 |

### 输出格式

#### 结构化表格列顺序

```
关键词 → 分类 → 属性标签 → 词频 → 建议动作 → 搜索量 → 竞争度 → PPC竞价 → ...
```

其中：
- `关键词`：原始关键词文本
- `分类`：一级核心词 / 二级属性词 / 三级场景词 / 品牌词 / 竞品词 / 不相关
- `属性标签`：命中的属性维度（如 `功能:降噪, 场景:运动`）
- `词频`：该词在原始数据中出现次数
- `建议动作`：建议投放 / 建议否定 / 仅Listing嵌入
- `搜索量` 及后续字段：来自原始数据，若无则留空

#### 群消息摘要卡片

```
📊 关键词整理完成 | <类目>-<产品定位>

━━ 统计 ━━
总词数：x → 去重后：x → 有效词：x

📌 一级核心词：x 个（品类认知类）
🎯 二级属性词：x 个（主力投放）
💰 三级场景词：x 个（高转化）
🏷 品牌/竞品词：x 个
✂ 建议否定词：x 个

🔗 完整表格：<钉钉文档链接>
```

## 触发与交互

**触发方式**：钉钉群内 @悟空 + 上传 Excel + 简短指令（如「整理关键词，类目：家居摆件-金色系」）

**输入**：
- 关键词原始数据 Excel（含关键词列，可选搜索量/竞争度/PPC 等指标列）
- 产品类目信息（用于加载对应词库）
- 可选：人工备注的特殊说明

**输出**：
- 结构化分类表格 → 回写钉钉文档（群关联钉盘）
- 摘要卡片 → 钉钉群消息回复

## Phase 2 扩展规划

### 扩展 A：接入卖家精灵 API
- 输入从 Excel 上传 → 升级为提供类目 + 筛选条件
- Skill 通过 HTTP 节点直接调用卖家精灵 API 拉取数据
- 搜索量、竞争度、PPC 等字段自动填充，不再依赖假设

### 扩展 B：Listing 文案 + 广告规划
- 输入从关键词 Excel → 升级为产品信息（文字描述 + 图片）
- Skill 自动调用分类后的关键词，按优先级埋入：
  - 标题：一级核心词 + 高搜索量二级属性词
  - 五点描述：二级属性词 + 三级场景词
  - 详情页/A+：三级长尾场景词
- 同步输出广告架构初稿：
  - 自动/手动投放分组建议
  - 预算分配建议
  - 否定关键词列表（精准否定 + 词组否定）

## 实现策略

**MVP Phase 1**：纯规则引擎，手动上传 Excel，悟空工作流内完成全流程

**Phase 2**：接入卖家精灵 API，输入环节自动化；引入 LLM 辅助判断语义模糊的关键词

选择混合渐进策略的理由：
- 与会议纪要「从最小可行单元开始验证」的共识一致
- 卖家精灵 API 尚未验证，数据格式尚未确定
- 先跑通业务逻辑闭环，再逐步增加复杂度
