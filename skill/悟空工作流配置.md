# 悟空工作流配置指南（LLM 驱动版本）

> 核心思路：将分类标准（`分类标准.md`）作为 AI Prompt，让悟空内置 AI 直接进行语义级分类判断。
> **无需手工维护词库**，切换类目只需在指令中说明产品类目即可。

## 前置条件

1. 企业钉钉已升级至 AI 2.0，具备「技能开发向导」入口
2. 已在悟空平台创建新 Skill，命名：`关键词整理助手`

## 工作流整体结构

```
触发器: 钉钉群 @提及 + 文件上传
  │
  ├─ 节点1: 输入解析
  │   读取钉钉消息附件中的 Excel → 解析为结构化数据表
  │   从用户消息中提取 product_category 变量
  │
  ├─ 节点2: 数据预处理
  │   去重 → 清洗 → 词频统计
  │
  ├─ 节点3: AI 分类（核心）⭐
  │   注入「分类标准.md」作为系统 Prompt
  │   关键词列表 + 产品类目 → 悟空 AI → 逐词分类
  │
  └─ 节点4: 输出组装
       生成结构化表格 → 回写钉钉文档
       生成摘要消息 → 回复钉钉群
```

## 节点 1: 输入解析

**悟空节点类型**: 「数据输入」→「表格解析」

| 参数 | 值 |
|------|-----|
| 输入来源 | 钉钉群消息附件（.xlsx / .csv） |
| 解析方式 | 自动识别表头 |
| 必需列 | 关键词 |
| 可选列 | 搜索量、竞争度、PPC竞价(USD)、ABA排名... |
| 输出变量名 | `raw_keyword_table` |

从用户消息中提取产品类目信息（如「家居摆件-金色系」），存为变量 `product_category`。

## 节点 2: 数据预处理

**悟空节点类型**: 「数据处理」→「表格处理」

- 关键词清洗：去首尾空格 → 统一小写 → 去特殊符号 → 合并多余空格
- 去重 + 词频统计：按「关键词」分组计数，每个唯一词保留一行（搜索量取最大值）
- 输出变量名: `preprocessed_table`

## 节点 3: AI 分类（核心）⭐

**悟空节点类型**: 「AI 处理」→「Prompt 模板」

### 步骤 3.1: 注入分类标准

将 `skill/分类标准.md` 的完整内容作为**系统级 Prompt**（或悟空「技能知识库」）注入。

### 步骤 3.2: 构建分类任务

Prompt 模板：

```
请对以下 {关键词数量} 个关键词进行分类。

**产品类目**: {product_category}

**关键词列表**:
{逐行列出 preprocessed_table 中的所有关键词}

**输出格式**（严格按此格式，每行一个）:
序号 | 关键词 | 分类 | 属性标签 | 建议动作 | 判断理由
```

### 步骤 3.3: AI 输出解析

AI 返回每行按 `|` 分割，提取：关键词、分类、属性标签、建议动作、判断理由。

新增四列到表格：`分类`、`属性标签`、`建议动作`、`判断理由`。

输出变量名: `classified_table`

### 设计优势

- **零词库维护**：AI 天然理解「降噪」是功能属性、「小户型」是场景信号词
- **跨类目通用**：切换类目只需改变 `product_category`，分类标准不变
- **可解释**：AI 输出「判断理由」列，运营人员可审查

## 节点 4: 输出组装

### 步骤 4.1: 生成结构化表格

| 参数 | 值 |
|------|-----|
| 目标 | 群关联钉盘 |
| 数据源 | `classified_table` |
| 列顺序 | 关键词 → 分类 → 属性标签 → 词频 → 建议动作 → 判断理由 → 搜索量 → 竞争度 → PPC竞价(USD) |
| 文档命名 | `关键词整理结果_{product_category}_{YYYYMMDD}` |

### 步骤 4.2: 生成群消息摘要

```
📊 关键词整理完成 | {product_category}

━━ 统计 ━━
总词数：{总词数} → 去重后：{去重后} → 有效词：{有效词}

📌 一级核心词：{x} 个（品类认知类）
🎯 二级属性词：{x} 个（主力投放）
💰 三级场景词：{x} 个（高转化）
🏷 品牌/竞品词：{x} 个
✂ 建议否定词：{x} 个

🔗 完整表格：[钉钉文档链接]
```

## 技能测试

1. 在沙箱环境配置全部节点
2. 将 `skill/分类标准.md` 内容配置为系统 Prompt
3. 使用 `skill/测试/示例关键词数据.csv` 测试
4. 检查 AI 分类结果合理性和摘要格式完整性
5. 确认后发布

## 切换类目

**无需修改任何配置。** 运营人员改变钉钉消息中的类目即可：

```
@悟空 整理关键词，类目：蓝牙耳机-降噪款
```
