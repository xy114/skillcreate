# 悟空工作流配置指南

> 本文档描述在悟空智能体平台（钉钉 AI 2.0 工作台）中配置本 Skill 各节点的步骤。
> 分类引擎的逻辑参考同目录下的 `分类引擎.py`（基于子串匹配，适配中文关键词）。

## 前置条件

1. 企业钉钉已升级至 AI 2.0，具备「技能开发向导」入口
2. 本 Skill 的四个词库 JSON 文件已作为「资源变量」上传至悟空
3. 已在悟空平台创建新 Skill，命名：`关键词整理助手`

## 工作流整体结构

```
触发器: 钉钉群 @提及 + 文件上传
  │
  ├─ 节点1: 输入解析
  │   读取钉钉消息附件中的 Excel → 解析为结构化数据表
  │
  ├─ 节点2: 数据预处理
  │   去重 → 清洗（去除特殊字符、统一小写） → 词频统计 → 添加「词频」列
  │
  ├─ 节点3: 分类引擎（核心）
  │   加载四个词库 → 逐行执行分类规则(子串匹配) → 添加「分类」「属性标签」「建议动作」列
  │
  └─ 节点4: 输出组装
       生成结构化表格 → 回写钉钉文档
       生成摘要消息 → 回复钉钉群
```

## 节点 1: 输入解析

**悟空节点类型**: 「数据输入」→「表格解析」

| 参数 | 值 |
|------|-----|
| 输入来源 | 钉钉群消息附件（.xlsx / .csv） |
| 解析方式 | 自动识别表头 |
| 必需列 | 关键词 |
| 可选列 | 搜索量、竞争度、PPC竞价(USD)、ABA排名... |
| 输出变量名 | `raw_keyword_table` |

## 节点 2: 数据预处理

**悟空节点类型**: 「数据处理」→「表格处理」→「自定义公式」

依次添加以下处理步骤：

### 步骤 2.1: 关键词清洗

```
清洗规则（对「关键词」列逐行执行）：
1. 去除首尾空格
2. 统一转为小写（英文部分）
3. 多个空格合并为一个
4. 去除 @#$%^&* 等非法符号
```

### 步骤 2.2: 去重 + 词频统计

```
按「关键词」列分组：
1. 统计每个唯一关键词的原始出现次数 → 写入「词频」列
2. 去重：每个关键词仅保留一行
3. 输出变量名: preprocessed_table
```

**⚠ 关键决策：去重保留哪一行的指标数据？**
当同一个关键词在原始数据中出现多次但搜索量/竞争度不同时，保留**搜索量最大**的那一行。这样分类结果使用的是该关键词的最佳表现数据。

## 节点 3: 分类引擎（核心）

**悟空节点类型**: 「条件分支」→ 嵌套使用

### 步骤 3.1: 加载词库资源

将四个 JSON 文件作为「资源变量」在工作流初始化时加载：

- `brand_db` = 品牌竞品词库.json
- `attr_db` = 属性词库.json
- `cat_db` = 品类词库.json
- `signal_db` = 场景信号词库.json

### 步骤 3.2: 分类规则分支（逐行处理）

**⚠ 核心原则**: 所有匹配使用**子串匹配**（检查词库中的词是否为关键词的子串），而非分词后集合匹配。原因：中文关键词如「金色摆件」无空格分隔，分词工具无法正确切分。

对 `preprocessed_table` 的每一行，按以下优先级依次判定（新增三列：`分类`、`属性标签`、`建议动作`）：

```
对每一行（关键词 = row['关键词'].lower()）:

  ┌─ 分支 1: 品牌/竞品词优先匹配 ─────────────────┐
  │ 遍历 brand_db.品牌词，若任一词 in 关键词 → 分类=品牌词, 建议动作=建议投放, 结束
  │ 遍历 brand_db.竞品词，若任一词 in 关键词 → 分类=竞品词, 建议动作=建议投放, 结束
  └──────────────────────────────────────────────┘
        │ 未命中
        ▼
  ┌─ 分支 2: 属性维度匹配 ─────────────────────────┐
  │ 对于四个属性维度（功能/规格/人群/场景），分别统计：
  │   功能维度命中数 = attr_db.功能属性[词列表] 中子串匹配关键词的数量
  │   规格维度命中数 = attr_db.规格属性[词列表] 中子串匹配关键词的数量
  │   人群维度命中数 = attr_db.人群属性[词列表] 中子串匹配关键词的数量
  │   场景维度命中数 = attr_db.场景属性[词列表] 中子串匹配关键词的数量
  │
  │ 命中维度 = 命中数 > 0 的维度列表
  │ 命中属性词列表 = 所有命中的具体词（用于标签拼接）
  │ 信号词命中 = signal_db 中任一信号词 in 关键词
  │
  │ ├─ 命中维度数 ≥ 2 → 分类=二级属性词, 建议动作=建议投放, 结束
  │ ├─ 命中维度数 = 1 且 信号词命中 → 分类=三级场景词, 建议动作=建议投放, 结束
  │ └─ 命中维度数 = 1 且 未命中信号词 → 分类=二级属性词, 建议动作=建议投放, 结束
  └──────────────────────────────────────────────┘
        │ 命中维度数 = 0
        ▼
  ┌─ 分支 3: 纯信号词判定 ─────────────────────────┐
  │ 若 信号词命中 → 分类=三级场景词, 建议动作=建议投放, 结束
  └──────────────────────────────────────────────┘
        │ 未命中
        ▼
  ┌─ 分支 4: 品类词判定 ───────────────────────────┐
  │ 若 cat_db.品类词列表 中任一品类词 in 关键词 → 分类=一级核心词, 建议动作=仅Listing嵌入, 结束
  └──────────────────────────────────────────────┘
        │ 未命中
        ▼
  ┌─ 兜底: 分类=不相关/宽泛词, 建议动作=建议否定
```

### 步骤 3.3: 属性标签拼接

```
遍历命中的各维度具体词，按维度拼接为标签字符串：
  格式: "功能:树脂,电镀; 场景:客厅; 规格:大号"
未命中任何属性词 → 填 "-"
```

### 步骤 3.4: 悟空节点实现建议

由于悟空工作流条件分支节点有限，推荐两种实现方式：

**方式A（纯条件分支）**: 适合悟空条件分支节点充足时。按上述伪代码逐级嵌套 `if/else` 条件节点。

## 节点 4: 输出组装

### 步骤 4.1: 生成结构化表格

**悟空节点类型**: 「输出」→「钉钉文档写入」

| 参数 | 值 |
|------|-----|
| 目标 | 群关联钉盘 / 指定文档路径 |
| 写入方式 | 覆盖写入（新建 Sheet） |
| 数据源 | `classified_table` |
| 列顺序 | 关键词 → 分类 → 属性标签 → 词频 → 建议动作 → 搜索量 → 竞争度 → PPC竞价(USD) |
| 文档命名 | `关键词整理结果_{产品类目}_{YYYYMMDD}` |

### 步骤 4.2: 生成群消息摘要

**悟空节点类型**: 「输出」→「钉钉群消息回复」

消息模板：

```
📊 关键词整理完成 | {类目名}

━━ 统计 ━━
总词数：{总词数} → 去重后：{去重后} → 有效词：{有效词}

📌 一级核心词：{一级数量} 个（品类认知类）
🎯 二级属性词：{二级数量} 个（主力投放）
💰 三级场景词：{三级数量} 个（高转化）
🏷 品牌/竞品词：{品牌+竞品数量} 个
✂ 建议否定词：{否定词数量} 个

🔗 完整表格：[钉钉文档链接]
```

## 技能测试与发布

1. 在沙箱环境完成全部节点配置
2. 使用 `skill/测试/示例关键词数据.csv` 作为输入，执行测试运行
3. 检查输出表格的 7 个验证用例：
   - `金色摆件` → 一级核心词
   - `树脂摆件 金色` → 二级属性词
   - `金属摆件 客厅` → 二级属性词
   - `情人节礼物 金色烛台` → 三级场景词
   - `宜家摆件同款` → 品牌词
   - `饰品` → 不相关/宽泛词
   - `家具` → 不相关/宽泛词
4. 检查群消息摘要格式正确
5. 确认无权限越界或数据泄露风险后提交审核发布

## 日常维护

- **切换类目**: 替换四个 JSON 词库资源文件，重新测试验证用例，重新发布
- **规则微调**: 分类阈值（如维度数判定）修改节点 3 的条件分支
- **新增列**: 输出列顺序调整在节点 4 中配置
