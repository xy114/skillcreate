# 跨境电商关键词整理 Skill

基于阿里悟空智能体平台的跨境电商关键词自动整理工具，服务于亚马逊产品开发立项流程。

**核心理念**：将分类标准作为 AI Prompt，让悟空内置 AI 直接进行语义级分类判断。**零词库维护**，切换类目只需改一行指令。

## 功能

- 接收运营人员上传的关键词 Excel 原始数据
- 自动去重清洗、词频统计
- AI 按三级分类体系（一级核心词 / 二级属性词 / 三级场景词 / 品牌词 / 竞品词 / 不相关）逐词分类
- 自动标注属性标签和建议投放动作
- 输出结构化表格 + 钉钉群消息摘要

## 目录结构

```
skill/
├── 分类标准.md               # 分类标准 Prompt（AI 判断依据）
├── 分类引擎.py               # 本地验证脚本（需 ANTHROPIC_API_KEY）
├── 悟空工作流配置.md          # 悟空平台 4 节点配置指南
└── 测试/
    ├── 示例关键词数据.csv    # 模拟关键词原始数据
    └── 分类结果.csv          # 引擎输出（自动生成）
```

## 快速验证

```bash
# 有 API Key 时：AI 直接分类
export ANTHROPIC_API_KEY=your-key
cd skill && python3 分类引擎.py "家居摆件-金色系"

# 无 API Key 时：输出 Prompt 预览
cd skill && python3 分类引擎.py
```

## 悟空平台部署

1. 在悟空平台创建新 Skill，命名「关键词整理助手」
2. 将 `skill/分类标准.md` 内容配置为系统 Prompt
3. 按 `skill/悟空工作流配置.md` 完成四个节点配置
4. 使用 `skill/测试/示例关键词数据.csv` 做测试运行
5. 验证通过后发布

## 日常使用

钉钉群内 @悟空 + 上传 Excel + 指令：

```
@悟空 整理关键词，类目：家居摆件-金色系
```

## 切换类目

**无需修改任何配置。** 运营人员改变类目指令即可：

```
@悟空 整理关键词，类目：蓝牙耳机-降噪款
```

AI 会根据新类目自动调整分类判断的上下文。

## 分类体系

| 分级 | 定义 | 策略 |
|------|------|------|
| 一级核心词 | 基础品类词，无属性修饰 | 品牌曝光，非主力投放 |
| 二级属性词 | 核心词 + 属性（功能/规格/人群/场景） | **主力投放** |
| 三级场景词 | 问题/场景/痛点驱动 | 高转化落地页 |
| 品牌词 | 具体品牌名 | 100% 覆盖防御 |
| 竞品词 | 竞品品牌名 | 差异化优势时投放 |
| 不相关/宽泛词 | 与类目无关或过于宽泛 | 建议否定 |
