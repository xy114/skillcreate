# 跨境电商关键词整理 Skill

基于阿里悟空智能体平台的跨境电商关键词自动整理工具，服务于亚马逊产品开发立项流程。

## 功能

- 接收运营人员上传的关键词 Excel 原始数据
- 自动去重清洗、词频统计
- 按三级分类体系（一级核心词 / 二级属性词 / 三级场景词 / 品牌词 / 竞品词 / 不相关）逐词分类
- 自动标注属性标签和建议投放动作
- 输出结构化表格 + 钉钉群消息摘要

## 目录结构

```
skill/
├── 词库/
│   ├── 品牌竞品词库.json    # 类目品牌名和竞品品牌名
│   ├── 属性词库.json        # 四维度属性词（功能/规格/人群/场景）
│   ├── 品类词库.json        # 基础品类名称集合
│   └── 场景信号词库.json     # 触发三级分类的场景/痛点信号词
├── 测试/
│   ├── 示例关键词数据.csv    # 模拟关键词原始数据
│   └── 分类结果.csv          # 分类引擎输出（自动生成）
├── 分类引擎.py               # 分类规则的 Python 验证脚本
└── 悟空工作流配置.md          # 悟空平台工作流各节点配置步骤
```

## 快速验证

```bash
# 确保 Python 3 已安装
cd skill
python3 分类引擎.py
```

输出示例：

## 悟空平台部署

1. 将 `skill/词库/` 下四个 JSON 文件上传至悟空资源文件
2. 在悟空平台创建新 Skill，命名「关键词整理助手」
3. 按 `skill/悟空工作流配置.md` 完成四个节点的配置
4. 使用 `skill/测试/示例关键词数据.csv` 做测试运行
5. 验证通过后发布

## 日常使用

钉钉群内 @悟空 + 上传 Excel + 指令：

```
@悟空 整理关键词，类目：家居摆件-金色系
```

## 切换类目

替换 `skill/词库/` 下四个 JSON 文件，重新在悟空平台发布 Skill。

## 分类体系

| 分级 | 定义 | 策略 |
|------|------|------|
| 一级核心词 | 基础品类词，无属性修饰 | 品牌曝光，非主力投放 |
| 二级属性词 | 核心词 + 属性（功能/规格/人群/场景） | **主力投放** |
| 三级场景词 | 问题/场景/痛点驱动 | 高转化落地页 |
| 品牌词 | 具体品牌名 | 100% 覆盖防御 |
| 竞品词 | 竞品品牌名 | 差异化优势时投放 |
| 不相关/宽泛词 | 与类目无关或过于宽泛 | 建议否定 |
